# Bundled Chicago typefaces

- `BigShouldersText-Bold.ttf`: Big Shoulders Text Bold, shared with the Divvy bot's announcement cards. Licensed under the SIL Open Font License; see `BigShoulders-OFL.txt`.
- `Roboto.ttf`: Roboto variable font (default regular), from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/roboto). See `Roboto-OFL.txt`.

Both are embedded into the executable; no runtime font downloads or browser are needed. Chicago recommends Big Shoulders for headings/posters and Roboto for sans-serif body copy: https://design.chicago.gov/typography/.
